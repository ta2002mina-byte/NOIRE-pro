NOIRÉ — The Dining Experience Complete Development Phase Prompts —
Next.js + Supabase

Tagline: “Your table. Your taste. Your story.”

GLOBAL RULES — APPLY TO EVERY PHASE

1.  First inspect the existing project before making changes.
2.  Reuse existing working code, components, authentication, database
    utilities, styling, and configuration whenever possible.
3.  Do NOT delete, replace, or rebuild working features without a clear
    technical reason.
4.  Do NOT create duplicate components, routes, tables, or utilities
    when an existing implementation can be extended.
5.  Use the Next.js + Supabase architecture already present in the
    project.
6.  Keep secrets server-side. Never expose SUPABASE_SERVICE_ROLE_KEY or
    private credentials to the client.
7.  Use Supabase RLS for customer/private data.
8.  Validate sensitive operations on the server.
9.  Never trust client-submitted prices, availability, permissions,
    milestone status, or reservation totals.
10. Include loading, empty, error, and success states.
11. Make important flows responsive and mobile-first.
12. Use semantic HTML, keyboard navigation, labels, focus states,
    contrast, and reduced-motion support.
13. Do not fabricate restaurant facts, sourcing, chef credentials,
    nutrition, events, or availability.
14. Use reusable, maintainable TypeScript components and utilities.
15. After each phase, run relevant lint, type-check, and build checks.
16. Complete ONLY the requested phase, then stop and wait for the next
    instruction.
